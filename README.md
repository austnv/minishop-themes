## 🚀 Установка темы

### Способ 1 — из Git (рекомендуется)

В админ-панели MiniShop → **Настройки → Темы → Установить из Git** укажите:

```
URL:      https://git.uvpn.app/austnv/minishop-themes
Ветка:    master
```

При обновлении репозитория тему можно переустановить одной кнопкой.

### Способ 2 — через ZIP

1. Соберите ZIP нужной темы (см. раздел «Разработка»).
2. В админ-панели MiniShop → **Настройки → Темы** загрузите архив.

## 🛠️ Разработка

### Структура темы

Каждая тема лежит в `themes/<key>/` и содержит:

```
themes/<key>/
├── LICENSE          # Копия корневого LICENSE (MIT)
├── README.md        # Описание темы
├── theme.json       # Конфиг MiniShop (обязательно)
├── style.css        # Кастомные стили (опционально)
└── preview.webp     # Превью 1280×800 (опционально)
```

`<key>` должен совпадать с полем `key` в `theme.json`.

### Ограничения MiniShop

- ZIP ≤ 20 МиБ, распакованный ≤ 100 МиБ, ≤ 2000 файлов
- CSS-файл ≤ 512 KiB
- **Запрещены** внешние ресурсы в CSS: `url(http://...)`, `@import`, `data:`
- **Запрещены** локальные шрифты через `@font-face` — MiniShop сам подтягивает шрифты по токенам `font_sans`, `font_logo`, `font_mono`
- CSS должен начинаться с селектора `.theme-key-<key>`
- Элементы вне `.app-shell` (тосты, дропдауны) стилизуются через `body:has(.theme-key-<key>)`
