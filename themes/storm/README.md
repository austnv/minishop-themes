# ⚡ Storm — Гроза

Тревожная динамичная тема в духе предгрозового неба. Тёмные облака медленно дрейфуют, раз в 24 секунды небо прорезает двойная вспышка молнии, активные элементы меню дрожат от электричества, а кнопки «разряжаются» при наведении. Не для повседневного использования — для тех, кто хочет живой интерфейс.

## ✨ Особенности

### Фон

- **Тёмные облака** — пять крупных эллипсов серо-синего цвета, медленно дрейфуют по горизонтали (80s на цикл).
- **Предгрозовое свечение** — холодный фиолетовый отблеск сверху + виньетка по краям.
- **Вспышки молний** — двойной удар (жёлтый + фиолетовый) раз в 24 секунды. Второй, более слабый одиночный удар — на 14-й секунде. Реализовано через `animation` на `opacity` с продуманными `%`-точками цикла.

### UI

- **Логотип** — переливающийся градиент фиолет → светлый фиолет → жёлтый + **вспышка** синхронно с молниями: `filter: brightness` + `drop-shadow` скачут в момент вспышек.
- **Активные пункты меню** — **дрожат** микросдвигами `±0.5px` (`@keyframes storm-tremble`). Пульсирующая жёлтая искра справа с двухцветным свечением.
- **Кнопки** — при наведении получают **разряд**: быстрая вибрация `±1.5px` каждые 4 секунды, пока курсор на кнопке. Плюс пробегающий блик.
- **Прогресс-бары** — как заряд молнии: жёлтые вспышки внутри фиолетового градиента с **резкими стопами**, пульсирующая яркость (`storm-charge`), сканирующий блеск.
- **Aurora-линия по правому краю сайдбара** — фиолетово-жёлтый градиент через `background-image`, без `position: relative`.
- **Иконки Lucide** — фиолетовые в обычном состоянии, **жёлтые** в активном. Двойное свечение.

### Доступность и мобильные

- **Вспышки молний полностью отключаются** при `prefers-reduced-motion: reduce`. Это критично: резкие вспышки яркого света могут быть опасны для людей с фотосенситивной эпилепсией.
- На `≤ 1023px` вспышки тоже **убираются полностью** — маленький экран и резкий свет дают дискомфорт.
- На мобильных также отключаются: дрожание меню, пульсации искр, пульсация логотипа.

## 🌗 Варианты

**Один вариант — `dark`.** Гроза бывает только в тёмное время суток. Светлый вариант разрушил бы всю концепцию: молнии на белом фоне — это не атмосфера, а курьёз.

## ⚠️ Предупреждение

Тема содержит **редкие вспышки яркого света** (раз в 24 секунды). Если у вас или ваших пользователей есть **фотосенситивная эпилепсия** — тема автоматически безопасна: при включённом `prefers-reduced-motion` (системная настройка «уменьшить движение») вспышки полностью отключаются. На мобильных устройствах вспышки также не показываются.

## ⚙️ Установка

Через админ-панель MiniShop → **Настройки → Темы → Установить из Git**:

```
URL:      https://github.com/austnv/minishop-themes
Ветка:    master
Подпапка: themes/storm
```

ZIP в репозитории не хранится — MiniShop собирает пакет сам из подпапки.
